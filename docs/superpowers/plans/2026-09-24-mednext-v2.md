# MedNeXt v2 Reference and Fused GRN Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a paper-faithful 3D MedNeXt v2 Base/Wide model with the existing checkpoint controls, portable evaluation export, adaptive convolution reuse, and an evidence-gated fused Triton GRN training path.

**Architecture:** Keep v2 in a separate model stack while sharing stable checkpointing, optimization policy, and export infrastructure. Generalize the operator registry so normalization operators carry no fake convolution geometry, build a pure-PyTorch GRN as the numerical oracle, then add an adaptive GRN wrapper whose CUDA implementation is selected as one integral training operation. Publish a bundled RTX 5090 rule only after isolated correctness and complete-model acceptance both pass.

**Tech Stack:** Python 3.10+, PyTorch 2.6+, Triton through `torch.library.triton_op`, pytest, Ruff, ONNX/ONNX Runtime, YAML policy v2.

**Spec:** `docs/superpowers/specs/2026-09-24-mednext-v2-design.md`

## Global Constraints

- Support 3D MedNeXt v2 only; context size is an input property, not a model variant.
- Base uses `C=32`; Wide uses `C=64`; both use block counts `(3,4,8,8,8,8,8,4,3)`, expansion ratios `(3,4,8,8,8,8,8,4,3)`, and k3 depthwise convolutions.
- GRN uses the paper's channel sum, `eps=1e-6`, and zero-initialized FP32 `gamma` and `beta`.
- FP16/BF16 GRN reductions and affine arithmetic use FP32; output is cast once to the input dtype and parameter gradients remain FP32.
- Evaluation, disabled-gradient execution, and export enter the reference GRN path before policy resolution or Triton import.
- Fused GRN dispatch is one `training` decision; forward, dX, dGamma, and dBeta are diagnostic measurements only.
- Existing v1 public behavior, module paths, parameter keys, policies, exports, and tests must remain unchanged.
- Model configuration and public factory arguments must remain YAML-friendly.
- The first public v2 release requires an evidence-backed positive fused-GRN rule on RTX 5090; no rule may be published from isolated timing alone.

## Review Focus

- Zero and near-zero channel norms must stay finite and use the zero subgradient; Task 2 pins reference forward/backward and Task 7 pins the fused path.
- Odd spatial dimensions must round-trip to the input shape through four resampling levels; Task 4 tests mixed odd/even axes and the minimum supported extent.
- A default `optimization="auto"` model in eval mode must export on a machine with no Triton import; Task 6 tests TorchScript, strict export, and ONNX from that path.
- Unsupported GRN tensors (CPU, FP32 fused request, noncontiguous layout, wrong rank, or disabled gradients) must choose reference without changing parameters; Tasks 5 and 7 exercise every guard.
- A policy condition that names convolution geometry must not match a geometry-free GRN descriptor; Task 1 tests absent facts and family-specific eligibility.

```python
def oracle(x, gamma, beta, eps=1e-6):
    work = x.float() if x.dtype in (torch.float16, torch.bfloat16) else x
    norm = torch.linalg.vector_norm(work, dim=(2, 3, 4), keepdim=True)
    ratio = norm / (norm.sum(dim=1, keepdim=True) + eps)
    return (work + gamma.to(work.dtype) * work * ratio + beta.to(work.dtype)).to(x.dtype)


def test_reference_grn_uses_channel_sum_and_zero_subgradient():
    module = GlobalResponseNorm3d(4).double()
    x = torch.zeros(2, 4, 3, 5, 7, dtype=torch.double, requires_grad=True)
    torch.testing.assert_close(module(x), oracle(x, module.gamma, module.beta))
    module(x).sum().backward()
    assert torch.isfinite(x.grad).all()


def test_reference_grn_gradcheck():
    module = GlobalResponseNorm3d(3).double()
    module.gamma.data.normal_()
    module.beta.data.normal_()
    x = torch.randn(2, 3, 2, 3, 4, dtype=torch.double, requires_grad=True)
    assert torch.autograd.gradcheck(module, (x,))
```

```python
def global_response_norm3d_reference(x, gamma, beta, eps=1e-6):
    if x.ndim != 5:
        raise ValueError("GRN expects an NCDHW tensor")
    work = x.float() if x.dtype in (torch.float16, torch.bfloat16) else x
    norm = torch.linalg.vector_norm(work, dim=(2, 3, 4), keepdim=True)
    ratio = norm / (norm.sum(dim=1, keepdim=True) + eps)
    output = work + gamma.to(work.dtype) * work * ratio + beta.to(work.dtype)
    return output.to(x.dtype)
```

```python
def _expansion_forward(self, x):
    return self.project(self.grn(self.activation(self.expand(x))))


def forward(self, x):
    residual = x
    x = self.norm(self.depthwise(x))
    x = (
        checkpoint(self._expansion_forward, x, use_reentrant=False)
        if self.checkpoint_expansion and self.training and torch.is_grad_enabled()
        else self._expansion_forward(x)
    )
    return x + residual if self.use_residual else x
```

```python
def forward(self, x):
    if not self.training or not torch.is_grad_enabled():
        return self._reference(x)
    context = _context_from_tensor(x, self.model_context, training=True)
    decision = self.resolver.resolve(self.descriptor, context, "training")
    if decision.implementation != "triton_fused_grn" or not self._tensor_eligible(x):
        return self._reference(x)
    try:
        from ._triton.grn import fused_global_response_norm3d
    except (ImportError, AttributeError):
        return self._reference(x)
    return fused_global_response_norm3d(x, self.gamma, self.beta, self.eps)
```
